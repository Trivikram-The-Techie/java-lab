# Week 07: String Handling in Java

## Objectives
- Understand internal mechanics of String, StringBuffer, and StringTokenizer.
- Analyze String immutability and the Java String Constant Pool (SCP).
- Compare performance tradeoffs between mutable StringBuffer and immutable String.

## Key Concepts
1. **String Immutability**: Once created, String objects cannot be changed in memory.
2. **StringBuffer**: Thread-safe mutable sequence of characters.
3. **StringTokenizer**: Legacy utility class to break a string into delimited tokens.
