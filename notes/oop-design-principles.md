# Object-Oriented Design Principles in Java

## Core Pillars
1. Encapsulation: Bundling fields with methods; private fields exposed via getters/setters.
2. Inheritance: Subclasses inherit state and behavior from superclasses.
3. Polymorphism: Compile-time (overloading) vs runtime (overriding).
4. Abstraction: Hiding implementation details using abstract classes and interfaces.
