1. Objective / Aim

To create and import user-defined packages, demonstrate access specifiers, and implement multiple inheritance using Java interfaces.

2. Concept & Theory

Packages group related classes and interfaces into a single namespace. Interfaces declare abstract method contracts that allow multiple inheritance and loose coupling across components.

3. Java Source Implementation
// Advanced Java Lab - Experiment 05
// Student: Trivikram | Roll No: 25EU02067
interface Printable {
    void print();
}

interface Showable {
    void show();
}

class LabReport implements Printable, Showable {
    private String title;

    public LabReport(String title) {
        this.title = title;
    }

    @Override
    public void print() {
        System.out.println("Output Generated: " + title);
    }

    @Override
    public void show() {
        System.out.println("Displaying UI Report for: " + title);
    }
}

public class Week5Demo {
    public static void main(String[] args) {
        LabReport report = new LabReport("Advanced Java Lab Week 5 Manual");
        report.print();
        report.show();
    }
}
